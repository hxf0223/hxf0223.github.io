## 1. Windows 下的 gz-sim 搭建

按照`gz-sim`官方文档，首先下载并安装[Pixi](https://pixi.prefix.dev/latest/)，`Pixi`是一个包管理工具。安装完成之后，`Pixi`应该会添加到系统PATH中。新开一个Powershell窗口，执行以下命令安装`gz-sim`：

```powershell
mkdir -p E:\work\gz\gz
cd E:\work\gz\gz

pixi init
```

此时，在`E:\work\gz`目录下会生成一个`pixi.toml`文件，将内容为空的`[dependencies]`替换为如下：

```toml
[target.win-64.activation.env]
QT_QPA_PLATFORM_PLUGIN_PATH="E:\\dev_libs\\Qt\\6.11.1\\msvc2022_64\\plugins\\platforms"
QML2_IMPORT_PATH="E:\\dev_libs\\Qt\\6.11.1\\msvc2022_64\\qt6\\qml"

[dependencies]
gz-sim = "10.*"
```

在安装`gz-sim`之前，设置`Pixi`的镜像源，将原本`[workspace]`中的`channels`替换为如下：

```toml
# 把原本的 conda-forge 通道换成清华镜像
channels = ["https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge"]
# 为其配置 conda-pypi-map ，使用 gh-proxy 镜像
conda-pypi-map = {"https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge" = "https://gh-proxy.org/https://raw.githubusercontent.com/prefix-dev/parselmouth/main/files/compressed_mapping.json"}
```

并添加段`[pypi-options]`，内容如下：

```toml
# 把 PyPI 源配置为清华镜像
[pypi-options]
index-url = "https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple"
```

### 1.1. 安装 gz-sim 及测试

安装命令如下：

```powershell
pixi install
```

使用如下测试命令启动 `gz-sim`：

```powershell
pixi shell
gz sim -v4 shapes.sdf

# 或者使用如下一条命令
pixi run gz sim -v4 shapes.sdf
```

> 测试发现在在退出 `gz-sim` 的时候，`gz-sim-gui-client.exe` 的清理出错，导致总是弹出错误提示对话框。参照官方文档[Source Installation on Windows 10 or 11](https://gazebosim.org/docs/latest/install_windows_src/)，应该可以修改 `gz-sim` 源码，编译安装到`Pixi`包管理器中。
