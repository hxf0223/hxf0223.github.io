VSCode 改用 MathJax 渲染数学公式

Created on May 12, 2024

2024   ·   VSCode   MathJax   ·   VSCode

首先安装Markdown Preview Enhanced插件，并做如下配置：

  • Ctrl+Shift+P → Markdown Preview Enhanced: Open Config Script (Global)

将如下内容添加到配置文件config.js中：

{
  "mathjaxConfig": {
    "tex": {
      "inlineMath": [["$", "$"], ["\\(", "\\)"]],
      "displayMath": [["$$", "$$"], ["\\[", "\\]"]],
      "tags": "ams"
    }
  }
}
